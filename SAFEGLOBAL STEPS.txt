INTRODUCE AFD
=============

Created AFD Profile
====================

az afd profile create `
  --profile-name safeglobal-afd `
  --resource-group safeglobal-rg `
  --sku Standard_AzureFrontDoor


NAVIGATE Traffic in AFD
=======================

az afd origin-group create `
  --resource-group safeglobal-rg `
  --profile-name safeglobal-afd `
  --origin-group-name safeglobal-gateway-og `
  --probe-request-type GET `
  --probe-protocol Https `
  --probe-path / `
  --sample-size 4 `
  --successful-samples-required 3
  


RE-CREATE origin Group
======================
az afd origin-group create `
  --resource-group safeglobal-rg `
  --profile-name safeglobal-afd `
  --origin-group-name safeglobal-gateway-og `
  --probe-request-type GET `
  --probe-protocol Https `
  --probe-path / `
  --probe-interval-in-seconds 30 `
  --sample-size 4 `
  --successful-samples-required 3
  
  Add gateway as origin in AFD
============================

az afd origin create `
  --resource-group safeglobal-rg `
  --profile-name safeglobal-afd `
  --origin-group-name safeglobal-gateway-og `
  --origin-name safeglobal-gateway-origin `
  --host-name safeglobal-gateway.azurewebsites.net `
  --origin-host-header safeglobal-gateway.azurewebsites.net `
  --http-port 80 `
  --https-port 443 `
  --priority 1 `
  --weight 100
 
 Create Public Front door endpoint (DNS)
 =======================================
 
 az afd endpoint create `
  --resource-group safeglobal-rg `
  --profile-name safeglobal-afd `
  --endpoint-name safeglobal-afd-endpoint


CREATE AFD Route
=================
az afd route create `
  --resource-group safeglobal-rg `
  --profile-name safeglobal-afd `
  --endpoint-name safeglobal-afd-endpoint `
  --route-name safeglobal-route `
  --origin-group safeglobal-gateway-og `
  --supported-protocols Http Https `
  --patterns-to-match "/*" `
  --forwarding-protocol HttpsOnly `
  --https-redirect Enabled `
  --link-to-default-domain Enabled
